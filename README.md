# CNN Image Classification with CIFAR-10

## Project Overview

This project implements a Convolutional Neural Network (CNN) using TensorFlow and Keras to classify images from the CIFAR-10 dataset.

The model performs image classification into 10 different object categories.

---

## Dataset

- CIFAR-10
- 60,000 color images
- 10 image classes
- Built-in TensorFlow dataset

---

## Technologies Used

- Python
- TensorFlow
- Keras
- NumPy
- Matplotlib

---

## Model Architecture

- Conv2D
- MaxPooling2D
- Conv2D
- MaxPooling2D
- Conv2D
- Flatten
- Dense
- Softmax Output

---

## Results

- Test Accuracy: **71.6%**

Training and validation accuracy/loss curves are included in the notebook.

Example predictions are also displayed after training.
